Privacy

Analysis activity

Token addresses and network selections are sent to the server and external blockchain or market-data services to produce reports. Recent assessments are stored and may appear in the public recent-analysis feed. Do not treat token lookups as private conversations.

Browser storage

Analysis history is also stored in your browser. Clearing browser data removes the local copy, not reports already stored on the server. External fonts and token images may cause requests to their hosting services.

Administration

Admin wallet addresses, roles, encrypted authenticator setup data, deployment records and operation logs are stored for access control and administration. Authorized admins share deployment records and operation logs. An HTTP-only session cookie maintains admin sign-in, with a configured 30-minute lifetime.

Security and external services

The server processes request information, including IP addresses, for rate limiting and security. Infrastructure providers may process connection metadata. Blockchain transactions and wallet addresses recorded on-chain are public and cannot be removed by clearing this website's data.

The X link opens an external profile. Account linking is not currently enabled. External services have their own privacy practices.
